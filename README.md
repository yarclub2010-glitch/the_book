# the_book

Визуальная новелла для браузера (HTML/JS).

## Структура проекта

```
index.html              — точка входа (будет добавлена)
src/                    — код игры
  engine/               — движок: показ сцен, диалоги, выборы, переменные, сохранения
  ui/                   — интерфейс: главное меню, окно диалога, история реплик, настройки
assets/                 — ресурсы
  backgrounds/          — фоны сцен
  characters/           — спрайты персонажей (по эмоциям: имя_эмоция.png)
  cg/                   — полноэкранные иллюстрации ключевых моментов
  ui/                   — кнопки, рамки, иконки
  audio/music/          — музыка
  audio/sfx/            — звуковые эффекты
  audio/voice/          — озвучка реплик
  fonts/                — шрифты
story/                  — сценарий
  chapters/             — главы: реплики, выборы, ветвления
docs/                   — сюжет, персонажи, схема ветвлений, заметки
```

## Скрипты

- `start-server.bat` — запустить локальный сервер и открыть http://localhost:8000 (нужен Python).
- `sync.bat` — скачать изменения с GitHub и отправить свои.
