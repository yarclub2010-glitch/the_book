# the_book

Визуальная новелла для браузера (HTML/JS). Шесть лет назад сестра оставила брату
записку — и мир разошёлся надвое. В каждом из миров живёт Тихон, и каждый
уверен, что в его доме завёлся призрак.

**Сейчас готово:**
- глава 1 «Буквы» — комната и кухня, загадка с магнитными буквами;
- глава 2 «Голоса» — комната Веры, колонка «Мири», книга-проводник, загадка с обрывками фраз;
- глава 3 «Ожог» — коридор, раскрытая книга, письмо лимонным соком и утюгом, ответ двойника;
- глава 4 «Два гудка» — утро, которое повторяется, спешащие часы, фото-якорь и первый обмен мирами;
- глава 5 «Сойти за своего» — Тихон в мире «Приходи»: Вера, наушники, вопрос двойнику паяльником, хлебница;
- глава 6 «Трек» — двойник в мире «Не приходи»: мама, пароль от чужого ноутбука, колонка «Мири», свой голос в чужой музыке;
- глава 7 «Лампа для ногтей» — записка в столе двойника, ультрафиолет, проступает «Не» — и развилка: показать Вере самому или оставить разговор двойнику;
- эпилог «Обмен» (ветка А), главы 8 «Вокзал» и 9 «Не» (ветка Б) — четыре концовки по доверию между героями;

- стартовое окно, сохранения, настройки, журнал реплик, дневник законов.

План глав, развилки и память истории — в `docs/главы.md`, загадки — в `docs/загадки.md`.

Фоны — картинки из `assets/backgrounds/` (имена = коды кадров из `docs/промпт-референсы.md`).
Поверх картинки код рисует только то, что живёт и меняется: буквы, записки, свет, поезда.

## Запуск

Игра использует ES-модули, поэтому её нужно открывать через сервер:

- дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000;
- или опубликуйте репозиторий через GitHub Pages.

## Управление

| Клавиша | Действие |
|---|---|
| Щелчок, Пробел, Enter | дальше |
| Ctrl (удерживать) | пропуск |
| A | авточтение |
| L | журнал реплик |
| 1–9 | перейти в место из списка внизу слева |
| F5 / F9 | быстрое сохранение / загрузка |
| F | во весь экран |
| Tab, затем Enter | выбрать предмет без мыши |
| Q | что дальше: герой вспоминает, чем занят |
| H | скрыть интерфейс |
| Esc | меню |

## Структура проекта

```
index.html                 — оболочка игры: сцена 16:9, диалог, меню, панели
src/main.js                — запуск
src/engine/engine.js       — движок: выполняет сценарий, диалоги, сохранения, настройки
src/engine/stage.js        — сцена: слои, камера (ракурсы, плавные наезды), переходы, тряска
src/engine/audio.js        — музыка, фоновые шумы и звуки (синтез в браузере, без файлов)
src/engine/art.js          — plate(): фон-картинка и перевод её пикселей в координаты сцены; SVG-фигуры
src/scenes/                — сцены: room-np (комната Тихона), kitchen (кухня в двух мирах),
                             vera-np (комната и стол Веры), phone (история колонки «Мири»),
                             hall (коридор и мастерская двойника), book (раскрытая книга в двух мирах)
src/ui/style.css           — оформление: субтитры мира «Не приходи», аниме-окно мира «Приходи»
story/chapters/            — сценарии глав (команды описаны в начале chapter1.js)
docs/                      — законы вселенной, сюжет, мир и стиль, загадки
prototype/                 — ранние наброски: футаж и коллаж
assets/                    — место для будущей графики и звука
```

## Как устроена глава

Игра нелинейная: игрок сам ходит между местами (панель внизу слева) и щёлкает по
предметам. Камера подходит к предмету только по щелчку; щелчок мимо, правая кнопка,
колесо вниз или Esc — отойти. Сюжет открывается находками.

Глава — файл в `story/chapters/` из частей:

- `locations` — места и какая сцена показывается в зависимости от времени суток;
- `intro` — короткая сценка в начале;
- `interact(сцена, предмет, состояние)` — особые реакции предметов: мысли, подход камеры
  (`shot`), переход (`go`), флажки (`set`), сценка (`beat`);
- `timers` — живой мир: скрипы, поезда, события (`after` — один раз через N секунд
  исследования, `every` — повторяется);
- `puzzles` — когда доступна загадка (сама загадка описана в сцене);
- `rules` — сценки, которые запускаются, когда выполнено условие (например, загадка решена).

Команды сценок: `scene`, `shot`, `say`, `think`, `narr`, `card`, `music`, `sfx`, `event`,
`shake`, `wait`, `hide`, `thought`, `hint`, `set`, `time`, `go`, `choice` (выбор игрока), `end`.
Правило с `repeat: true` может срабатывать снова; `beat` и `set` таймера могут быть функциями состояния.

Предметы-истории (мысли героя) описаны в файлах сцен рядом с их зонами.

## Щелчки по предметам (активные зоны)

Картинка сцены никогда не ловит щелчки: она лежит в слое `art` с `pointer-events: none`.
Поверх неё движок сам кладёт слой невидимых **активных зон** из описания сцены — поэтому
новые предметы, свет и эффекты не могут их перекрыть.

```js
hotspots: [
  { id: 'clock', label: 'Часы', shape: A.zoneCircle(P(0.7, 2.28, 0), 32),
    lines: ['Спешат на три минуты…', 'Раньше их подводила Вера.'] },
  { id: 'LХ', group: 'letters', shape: … }, // зона загадки
]
```

- Группа `look` (по умолчанию) — осмотр: включается, пока на экране реплика; щелчок
  показывает мысль героя рядом с предметом, сюжет не листается; повторные щелчки — следующие мысли.
- Другие группы включаются только во время своей загадки (`['puzzle', 'letters']`).
- Формы для сцен-картинок — в пикселях картинки: `B.rect(x0, y0, x1, y1)`, `B.circle(x, y, r)`,
  `B.poly([[x, y], …])`, ракурс — `B.shot(cx, cy, ширина)`, где `B = A.plate(путь, 1376, 768)`.
  Мелкие предметы — позже в списке, чтобы лежать сверху.
- Проверка: `game.stage.auditHotspots()` в консоли — какие зоны перекрыты; открыть игру
  с `?zones` — все зоны видны контурами.
