# the_book

Визуальная новелла для браузера (HTML/JS). Шесть лет назад капля дождя размыла одно
слово в записке — и мир разошёлся надвое. В каждом из миров живёт Тихон, и каждый
уверен, что в его доме завёлся призрак.

**Сейчас готово:** глава 1 «Буквы» — три сцены, загадка с магнитными буквами,
стартовое окно, сохранения, настройки, журнал реплик.

## Запуск

Игра использует ES-модули, поэтому её нужно открывать через сервер:

- дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000;
- или опубликуйте репозиторий через GitHub Pages.

## Управление

| Клавиша | Действие |
|---|---|
| Щелчок, Пробел, Enter | дальше |
| Ctrl (удерживать) | пропуск |
| A | авточтение |
| L или колесо вверх | журнал реплик |
| H | скрыть интерфейс |
| Esc | меню |

## Структура проекта

```
index.html                 — оболочка игры: сцена 16:9, диалог, меню, панели
src/main.js                — запуск
src/engine/engine.js       — движок: выполняет сценарий, диалоги, сохранения, настройки
src/engine/stage.js        — сцена: слои, камера (ракурсы, плавные наезды), переходы, тряска
src/engine/audio.js        — музыка, фоновые шумы и звуки (синтез в браузере, без файлов)
src/engine/art.js          — перспектива комнат и SVG-фигуры для рисования сцен
src/scenes/                — сцены: room-np (комната Тихона), kitchen (кухня в двух мирах)
src/ui/style.css           — оформление: субтитры мира «Не приходи», аниме-окно мира «Приходи»
story/chapters/chapter1.js — сценарий главы 1 (команды описаны в начале файла)
docs/                      — законы вселенной, сюжет, мир и стиль, загадки
prototype/                 — ранние наброски: футаж и коллаж
assets/                    — место для будущей графики и звука
```

## Как писать сценарий

Глава — список команд в `story/chapters/`. Например:

```js
['scene', 'kitchen-np', { shot: 'window', transition: 'fade' }],
['music', 'np-morning'],
['shot', 'fridge', { dur: 3 }],
['say', 't', 'Буквы.'],
['sfx', 'horns', { caption: 'два коротких гудка' }],
['puzzle', 'letters'],
```

Ракурсы (`shot`) задаются в файле сцены: прямоугольник кадра в координатах 1600×900,
камера переезжает между ними плавно.

## Скрипты

- `start-server.bat` — локальный сервер.
- `sync.bat` — скачать изменения с GitHub и отправить свои.
